# AI Personal Finance Analyzer

## Overview
An intelligent dashboard for analyzing personal transaction data using machine learning and visualization.

## Features
- Expense categorization
- Anomaly detection
- Future expense prediction
- Interactive visualizations
- AI-driven financial insights

## Usage
1. Upload your transaction CSV file.
2. View dashboard: transactions, category pie chart, expense histogram.
3. See ML features: anomaly detection, expense prediction, AI insights.

## Example Output
- Your food spending is high this month.
- Entertainment spending increased.
- Highest expense: Amazon (1500)
